# AI Contribution Policy

We welcome the use of generative AI tools to help you write code, documentation, and tests for this project. 

However, to maintain repository health, all contributors must adhere to the following rules:

* **You are responsible:** You own the code you submit. You must fully understand every line of AI-generated code in your Pull Request. 
* **No blind copying:** Do not submit code you cannot personally explain, debug, or maintain.
* **Testing:** AI-generated code must pass all existing CI/CD checks and include relevant unit tests.
* **Code Review:** Submissions will be held to the same strict standards of review as human-written code. Low-quality, bloated, or hallucinatory AI code will be rejected.
