Need Help?
Adding Observables
Observable Type: Enter the observable type.

Observable Value: Add it's value or any required information.

Time: Enter the time zone where the observable was seen, the number of times it was seen, and the first and last times it was observed.

Observable Relationship: Establishes a relationship between an attacker and its target or between an observable and the victim. This field will only be active if a relationship can be established.

If attacker is selected then an attacker name must be added. If you don't know who the attacker is at this point, just add unknown.

You may also select benign if the observable is not related to either the attacker or the target.
